# ESCO v1.1.1 Skills & Occupations Taxonomy Dataset

This dataset contains the official, verified **ESCO (European Skills, Competences, Qualifications and Occupations)** taxonomy by the European Commission, ready for Hire Q's skill normalization pipeline.

## 📊 Dataset Statistics:
- **Canonical Skills (`skills.csv`):** 13,896 standardized skills/competences.
- **Synonyms & Alternative Forms (`ALTLABELS`):** 97,483 pre-mapped variations.
- **Total Searchable Vocabulary:** 111,379 validated terms.
- **Occupations (`occupations.csv`):** Standard job roles mapped to skill requirements.
- **Skill Groups (`skillGroups.csv`):** Hierarchical competency clusters and domains.

## 📁 Files in this Directory:
1. `skills.csv`: Canonical skills with preferred label, alternative labels, skill type, and definition.
2. `skillGroups.csv`: The skill classification hierarchy tree.
3. `skills_hierarchy.csv`: Parent-child relations between skill groups and atomic skills.
4. `occupations.csv`: Standardized occupation titles and definitions.
5. `occupation_skill_relations.csv`: Links between occupations and required/essential skills.
6. `ISCOGroups.csv`: International Standard Classification of Occupations groupings.
